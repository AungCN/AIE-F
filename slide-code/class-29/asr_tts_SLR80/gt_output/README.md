## How to Run

gt_output ဖိုလ်ဒါထဲဝင်ပြီး `python -m http.server 8080` ဆိုပြီး ရိုက်ထည့်ရင် browser ကနေလည်း GT output တွေကို တစ်ဖိုင်ချင်း နားထောင်ကြည့်လို့ ရပါတယ်။  
အောက်ပါလိုမျိုး screen ကို မြင်ရပါလိမ့်မယ်။
